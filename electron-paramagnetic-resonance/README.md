# Digital RF-Receiving Technology and Electron Paramagnetic Resonance

## Overview
This experiment investigated radio-frequency signal processing and electron paramagnetic resonance (EPR) spectroscopy using software-defined radio techniques and microwave receiving systems.

## Focus
- RF frequency mixing and signal modulation
- Software-defined radio (SDR) and heterodyne reception
- Spectral analysis using HDSDR software
- Continuous-wave EPR spectroscopy
- Landé g-factor determination using DPPH
- EPR measurements of ultramarine samples
- Signal extraction from waterfall images
- Comparison of direct-mixing and PLL-LNB detection

## Key Results
- DPPH resonance fields: approximately 0.356–0.360 T
- Experimentally determined DPPH Landé factors: 2.094–2.113
- EPR signals detected across multiple ultramarine dilution ratios
- Relative microwave frequency difference between receiver configurations: approximately 0.013%

## Summary
The experiment combined RF engineering and magnetic resonance spectroscopy to investigate paramagnetic materials. Software-defined radio reception, frequency mixing, and image-based signal processing were used to identify resonance features and extract magnetic resonance parameters, while highlighting the importance of magnetic-field calibration.
